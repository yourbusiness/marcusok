"@marcusok/excel-exporter": minor
---

Progress overlay is now on by default and configurable through a new `overlay` option on `exportExcel` / `exportTable` / `exportEcharts`: omitted or `true` shows the overlay with default export texts, `false` disables it entirely (nothing mounted, no extra frame yielded), and a `ProgressOverlayOptions` object customizes texts, delay, theme, etc. (custom texts are merged with the export defaults). The overlay itself moved to a new shared package, `@marcusok/progress-overlay` (zero runtime dependencies, also usable standalone); it is now a regular dependency of this package. The `@marcusok/excel-exporter/overlay` subpath remains as a compatibility layer: `exportExcelWithOverlay(options, overlay?)` is now equivalent to `exportExcel({ ...options, overlay })`, and `showExportOverlay` forwards to the shared package. Note two API adjustments from the move: overlay texts use a `text.phases` map (`{ building: "…" }` instead of the previous flat `text.building` fields), and the handle methods are `setProgress(p)` / `setPhase(key)` / `close()` instead of `handleProgress` / `handlePhase`. Node/SSR behavior is unchanged (no-op without a `document`).
